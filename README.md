## 🖥️ Features

- **Boot Sequence** — Terminal-style startup sequence with Access Granted animation
- **OS-Style Navigation** — Identity, Arsenal, Mission Logs, Certifications, Timeline, Threat Intel and Contact Terminal
- **Mission Dossiers** — Expandable project information
- **Interactive Contact Terminal** — Commands such as `help`, `whoami`, `github`, `sudo`, etc.
- **Cybersecurity Interface** — HUD-style interface with scanlines, grid backgrounds and glass panels
- **Easter Eggs** — Konami Code and browser-console interactions
- **Cursor Spotlight** — Interactive cursor-based visual effects
- **Responsive Design** — Optimized for desktop, tablet and mobile
- **SEO Ready** — Metadata and accessible navigation
- **Static Export** — Can be deployed to static hosting platforms
